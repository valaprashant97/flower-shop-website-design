## 🌺 Overview

The **Flower Shop Website** is a front-end web design template created for florists, flower shops, and gift stores. It features a fresh, floral color palette, smooth transitions, interactive product hover effects, customer reviews, a contact form, and a pure CSS mobile navigation drawer.

---

## 📑 Website Sections

1. **Header & Navigation**:
   - Brand logo with floral icon.
   - Smooth navigation links (`Home`, `About`, `Products`, `Review`, `Contact`).
   - Quick utility icons: Wishlist/Heart, Cart, User Profile.
   - Mobile hamburger menu button.

2. **Hero Section (`#Home`)**:
   - High-resolution hero background with call-to-action button (*Shop Now*).

3. **About Section (`#About`)**:
   - Autoplaying muted looping promotional video.
   - "Why Choose Us" story and value proposition with *Learn More* CTA.

4. **Service Highlights (`.icons-container`)**:
   - 🚚 **Free Delivery**: On all orders.
   - 💰 **10 Days Returns**: Moneyback guarantee.
   - 🎁 **Offer & Gift**: Available on special orders.
   - 🔒 **Secure Payment**: Protected and verified transactions.

5. **Latest Products Showcase (`#Products`)**:
   - Product grid with cards showcasing flower pots, discounts, interactive buttons, and prices.

6. **Customer Reviews (`#Review`)**:
   - Social proof with customer ratings, review snippets, and customer profiles.

7. **Contact Us (`#Contact`)**:
   - Contact form alongside custom illustration banner.

8. **Footer**:
   - Quick navigation links, extra links, service locations, contact details, and copyright information.

## 🛠️ Technologies Used

- **HTML5**: Semantic elements (`<header>`, `<nav>`, `<section>`, `<video>`, `<footer>`).

## 🚀 Getting Started

No build tools or package managers required! You can view and edit the project immediately.

### 1. Clone the repository

```bash
git clone https://github.com/valaprashant97/flower-shop-website-design.git
```

### 2. Open in your browser

- Navigate to the project directory:
  ```bash
  cd flower-shop-website-design
  ```
- Open `index.html` directly in your preferred web browser:
  - **Windows**: Double-click `index.html` or run:
    ```powershell
    start index.html
    ```
  - **macOS**:
    ```bash
    open index.html
    ```
  - **Linux**:
    ```bash
    xdg-open index.html
    ```

### 3. Using VS Code Live Server (Optional)

If you are using Visual Studio Code:
1. Install the **Live Server** extension (`ritwickdey.LiveServer`).
2. Right-click `index.html` and select **Open with Live Server**.
